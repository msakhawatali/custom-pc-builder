# Custom PC Builder

A production-style full-stack e-commerce platform that allows users to build their own custom PCs, purchase individual computer components, and order pre-built gaming or office PCs.

This project is being developed using an industry-standard software development workflow, including GitHub Issues, feature branches, Pull Requests, code reviews, CI/CD, and agile planning.

---

## 🚀 Features

### Customer Features

* User Registration & Login
* Browse Products
* Product Search & Filtering
* Product Comparison
* Wishlist
* Shopping Cart
* Coupon System
* Checkout
* Order Tracking
* Product Reviews
* Custom PC Builder
* Compatibility Validation
* Save Custom Builds

### Admin Features

* Dashboard
* Product Management
* Category Management
* Brand Management
* Inventory Management
* Order Management
* User Management
* Coupon Management
* Review Moderation
